Four signals that belong in the same conversation.

Performance and sustainability are connected. EcoCode places them in a single report so a trade-off is visible before it reaches production.

Time complexity

03

Energy consumption

Watt-hours per run, expressed as a number that can be tracked instead of guessed.

04

Carbon emissions

Energy converted to grams of CO₂e using a fixed demonstration grid factor.

EXAMPLE / BEFORE → AFTERPython
# Before · every pair is compared
for i in range(len(items)):
    for j in range(i + 1, len(items)):
        if items[i] == items[j]:
            duplicates.append(items[i])

# After · sort, then compare neighbours
ordered = sorted(items)
for prev, cur in zip(ordered, ordered[1:]):
    if prev == cur:
        duplicates.append(cur)

02 / OPTIMIZATION

A rewrite you can inspect, not a mystery score.

The comparison view puts both implementations next to each other, highlights the changed lines and restates the four metrics for each version.

  • Nested pairwise comparison becomes a sorted adjacent scan.
  • Complexity moves from O(n²) toward O(n log n).
  • Energy and carbon are shown as relative reductions, clearly marked as examples.
